# YOUCODE EVENTS  


## Project purpose :
In 5 days and as a team, finalize the Figma model of the YouCode Events site, then integrate it into five static HTML5 and CSS3 pages, mobile-first and accessible. All code goes through a common GitHub repository: Git Flow branches, Pull Requests, and code reviews.  
## About The Project : 

YouCode organizes workshops, conferences, hackathons and meetings with professionals all year round, announced on several channels without a single entry point.

Your team is responsible for designing and integrating YouCode Events, a fictional site that presents and allows you to register for these events. It must be pleasant on phone, tablet and computer, and accessible to everyone.

This brief is collective: it is carried out as a team, on a single GitHub repository. Its goal is to progress on Git and GitHub by working with several people on the same code.  

## The Mession  
Using the wireframes and the initial Figma model, design the site model as a team, then integrate it into static and responsive web pages, respecting:

la maquette et son Design System ;
HTML5 semantics;
a mobile-first approach with media queries;
web accessibility principles;
Git Flow on a common GitHub repository, with Pull Requests and code reviews;
a project organization with Jira or GitHub Projects.  

## Planification : 
the product planification where based on jira platform, under Scrum, Kanban Framwork, The scrum master where the responsable to create the **product backlog**,  
based on **user story** , each Scrum member has the mession to create a user story based on their product page,  
The Scrum master managed jira **Sprint Backlog** as he assigned Tickets to each developer.

## Technologies
The Project Made By Static Technologies such as  :  
HTML5, css, Flex box, grid,  
Planification using : Jira scrum framework  
collaboration : Git/Github
